# Overcoming the Train Problem

电车难题主题的贪吃蛇小游戏，单文件 HTML，可直接在浏览器中打开。

## 玩法

- 你是失控电车的驾驶员，撞到轨道上被绑住的小人会让车体变长
- 连续撞击触发 combo，分数和长度成倍增长
- 撞墙或撞到自己 = GAME OVER
- WASD / 方向键操作，移动端有虚拟方向键
- 左侧扳道工小人会跟着你的下一个方向摆动操纵杆
