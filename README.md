# Overcoming the Train Problem

电车难题主题的贪吃蛇小游戏，单文件 HTML，可直接在浏览器中打开。

## 在线试玩

- 国际：https://opqxxxpqo.github.io/overcoming-the-train-problem/
- 国内备用（Render）：见仓库部署设置

## 玩法

- 你是失控电车的驾驶员
- 解决轨道上被绑住的小人（每个 = 一道难题），车体随之变长
- **连击系统**：连续不间断地解决难题触发 combo，每节加成倍增长（连撞 3 个 = 1+2+3=6 分）
- 撞墙或撞到自己 = GAME OVER
- WASD / 方向键操作；移动端有虚拟方向键
- 左侧扳道工小人会跟着你的下一个方向左右翻转 / 上下倾斜
- 点 START 后有 3-2-1-GO! 倒计时
- 封面右上角 `EN / 中文` 按钮切换中英文，偏好存在浏览器

## 隐藏结局

游戏内嵌了三个隐藏结局，需要玩家自己探索：

1. **弑己**：开车撞向某个特定位置触发，提示 hint 在画面布局里
2. **道德高尚模式 → 堕落**：10 秒不撞任何人会自动进入；进入后规则反转 —— 撞到任何人即失败，活的越久分数越高，路人凭空闪烁两下后出现，3 秒后消失，越往后生成越密集
3. **恶魔结局**：游戏开始的初始状态（车体未生长）会出现红色 `漂移 → 恶魔` 按钮 / 也可按空格触发；电车横过来 2 格宽，可同时碾压两行人，最终车毁人亡时解锁
